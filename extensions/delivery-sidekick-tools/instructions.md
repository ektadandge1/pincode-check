## When to use

Use this tool when the merchant asks about delivery estimates, postal-code coverage, product ETA rules, fulfillment locations, pickup, local delivery, shipping methods, or delivery-check performance.

## Guidelines

- Treat the returned configuration as read-only.
- State clearly when no rules or recent checks exist.
- Use the returned app links to direct merchants to the correct configuration page.
- Do not claim that a destination is serviceable without a postal-code check.
